# Catégories de dashboards
{: .fs-8 }

Organisation des dashboards par thématiques
{: .fs-5 .fw-300 }

---

## Présentation

Les **catégories** permettent d'organiser vos dashboards par thèmes ou domaines fonctionnels. Dans le Visualizer, les dashboards sont regroupés par catégorie dans le menu de navigation.

---

## Créer une catégorie

### Accès

1. Dans le menu, cliquez sur **Catégories**
2. Cliquez sur **Nouveau**

### Configuration

| Champ | Description | Exemple |
|:------|:------------|:--------|
| **Titre** | Nom de la catégorie | `Ventes`, `Production`, `RH` |

---

## Associer un dashboard à une catégorie

1. Modifiez le dashboard concerné
2. Dans le champ **Catégorie**, sélectionnez la catégorie souhaitée
3. Validez

{: .note }
> Un dashboard ne peut appartenir qu'à une seule catégorie. Sélectionnez `NO_CATEGORY` pour un dashboard non classé.

---

## Affichage dans le Visualizer

Dans le Visualizer, les catégories s'affichent dans le menu de navigation :

```
📁 Ventes
   ├── Dashboard CA mensuel
   ├── Dashboard Pipeline
   └── Dashboard Prévisions

📁 Production
   ├── Dashboard Suivi quotidien
   └── Dashboard Qualité

📁 Non classés
   └── Dashboard Test
```

---

## Bonnes pratiques

### Organisation recommandée

| Type d'organisation | Exemples de catégories |
|:--------------------|:-----------------------|
| **Par service** | Ventes, Marketing, Production, RH, Finance |
| **Par projet** | Projet Alpha, Projet Beta, Maintenance |
| **Par fréquence** | Quotidien, Hebdomadaire, Mensuel |
| **Par niveau** | Direction, Management, Opérationnel |

### Conseils

- **Limitez le nombre** : 5-10 catégories maximum pour une navigation claire
- **Nommez clairement** : Utilisez des noms explicites et courts
- **Cohérence** : Adoptez une convention de nommage uniforme
