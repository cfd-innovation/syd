# Connecteurs
{: .fs-8 }

Configuration des sources de données
{: .fs-5 .fw-300 }

---

## Présentation

Les **connecteurs** permettent de configurer les différentes sources de données qui alimenteront vos modules et dashboards. SYD supporte plusieurs types de connecteurs :

| Type | Description |
|:-----|:------------|
| **Bases de données** | Connexions directes à des SGBD (MySQL, DB2, SQL Server...) |
| **Webservices** | Appels à des APIs REST |
| **Requêtes SQL** | Requêtes préparées réutilisables |
| **Requêtes Builder** | Éditeur visuel de requêtes |

---

## Accès aux connecteurs

Dans le menu de navigation du Builder, cliquez sur **Connecteurs** pour accéder à la liste des connecteurs configurés.
